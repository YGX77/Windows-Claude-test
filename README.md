Ladybird for Windows

An independent Windows port of Ladybird, bringing its browser engine to Windows.

The browser is already capable of launching and loading web pages on Windows. Development now focuses on improving stability, fixing bugs, and making the experience more reliable.

[!IMPORTANT]
This project is experimental and under active development. It is not an official Ladybird release.

About

Ladybird is an independent web browser built around its own browser engine and modern web standards.

This project focuses on bringing Ladybird to Windows while preserving its original architecture and functionality wherever possible.

The goal is simple: make Ladybird work reliably on Windows and build a strong community around its development.
